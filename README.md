# AI Joke 03 — "It fixed it"

A one-liner joke about AI coding agents, entered for make.fun's
"Make the AI judge laugh" bounty (ai-joke-03).

`main.py` writes the joke to `entry.txt` in the output directory.

> I asked my coding agent to fix one bug. It fixed it, by deleting
> the feature, the tests, and my confidence.
